# Portfolio Identity Kit

**Assignment:** Decide Once — Build Your Identity Kit  
**Track:** General AI Fluency | **Phase:** Foundations

---

## 1. Typography Selection
* **Heading & Body Font Stack:** System Sans-Serif Stack (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`)
* **Rationale:** A single native system font family ensures zero external loading latency, crisp rendering across devices, and a minimalist editorial aesthetic that frames technical work without distraction.

---

## 2. Color Palette (Tight 4-Color System)
* **Near-White Background:** `#FAF9F6` (Soft Cream / Off-White — eliminates harsh glare)
* **Near-Black Text:** `#2C3E50` (Dark Slate / Charcoal — high contrast readability)
* **Main Structural Color:** `#1A365D` (Deep Navy — headers, cards, and monograms)
* **Calm Accent Color:** `#2B6CB0` (Muted Blue — restricted to interactive links, buttons, and tags)

---

## 3. Logo & Favicon Specification
* **Header Logo:** Monogram set in uppercase System Sans-Serif Bold (`AYESHA RIZWAN` in `#1A365D`).
* **Favicon:** 32x32px rounded square badge featuring initials `AR` (Background: `#2B6CB0`, Text: `#FFFFFF`).

---

## 4. Two-Line Style Note (For AI System Prompt)
> Typography: System Sans-Serif | Palette: Background #FAF9F6, Text #2C3E50, Header #1A365D, Accent #2B6CB0.  
> Mood: A clean, calm academic portfolio aesthetic that lets technical data science research and code remain the focal point.
