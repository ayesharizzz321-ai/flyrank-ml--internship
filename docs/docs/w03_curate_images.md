## 3. Ruthless Curation: Rejection Log (Graded Discernment)

* **Prompt Used:** *"Futuristic 3D neural network hologram with glowing neon data particle streams."*
* **Decision:** **REJECTED**
* **Reasoning:** It feels like cheap stock art that upstages the actual work. It offers zero proof of capability, distracts the reader from reading technical summaries, and breaks the quiet editorial mood of the portfolio.

### Rejected AI Asset 2: Generated Model Comparison Table Graphic
* **Prompt Used:** *"Modern clean UI table showing accuracy scores for machine learning algorithms."*
* **Decision:** **REJECTED**
* **Reasoning:** The generated graphic hallucinated inconsistent column alignment and fake decimal values. A real cropped screenshot of the executed Scikit-Learn classification report directly from Google Colab was used instead.
