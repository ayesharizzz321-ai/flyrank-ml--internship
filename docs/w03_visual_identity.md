# Week 03 Deliverable: Portfolio Visual Identity & Judgment Framework

**Track:** General AI Fluency | **Phase:** Foundations  
**Assignment:** Consistency, Not Talent (and Frame, Not Upstage)

---

## 1. Portfolio Visual Identity Ruleset

To create a clean, intentional visual presence without relying on complex design talent, this portfolio enforces a minimalist design system.

### Color Palette
* **Background:** `#FAF9F6` (Off-white / Soft Cream) — Reduces eye strain compared to pure `#FFFFFF`.
* **Primary Text:** `#2C3E50` (Dark Charcoal / Slate) — Soft contrast for maximum readability.
* **Accent Color:** `#2B6CB0` (Muted Navy Blue) — Restricted strictly to links, active navigation items, and structural tags.
* **Border Color:** `#E2E8F0` (Light Slate) — For subtle container outlines.

### Typography & Layout
* **Font Family:** System Sans-Serif stack (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`).
* **Content Width:** Max `800px` centered container to maintain optimal line lengths for reading technical write-ups.
* **Spacing:** Consistent `16px` / `24px` block padding across all project pages.

---

## 2. Core Principle: "Frame, Not Upstage"

The visual interface is designed to fade into the background so that the code, data analysis, and technical models take center stage.

* **What is Included:** Neutral card borders, clear section headers, clean typography hierarchy, and direct code snippets.
* **What is Excluded:** Heavy drop shadows, background particle effects, complex gradients, or distracting animations.

---

## 3. AI Image Selection & Judgment Log

Applying critical judgment to visual assets means selecting only graphics that support real proof of work and rejecting decorative fluff.

| Asset Candidate | Source / Prompt | Decision | Judgment Rationale |
| :--- | :--- | :--- | :--- |
| **Project Header Icon** | AI Generated: *"Minimalist vector line art of data pipeline, dark blue on off-white background."* | **ACCEPTED** | Clean, monochromatic icon that matches the site palette and signals the project topic without distracting from the text. |
| **Neural Net Diagram** | AI Generated: *"3D glowing neon neural network hologram with cyber lights."* | **REJECTED** | Generic stock art. Adds no technical value, looks flashy, and upstages the actual research content. |
| **Model Metrics Heatmap** | Real Screenshot from Google Colab / Seaborn | **ACCEPTED** | Provides authentic proof of work with exact numerical values from the executed notebook. AI charts risk hallucinating values. |
